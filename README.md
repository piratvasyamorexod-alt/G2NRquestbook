# G2NRquestbook

Обновленный штатный журнал Gothic II «Ночь Ворона» для Union на движке 2.6 (fix). Показывает записи игры и активного мода. Работает отдельно от Odyssee Quest Inspector.

## Управление

Открой журнал штатной клавишей, по умолчанию **L**. Вкладки переключаются кликом, стрелками влево и вправо или Tab. Клик по названию показывает запись справа. Стрелки вверх и вниз меняют выбранную запись. Колесико прокручивает колонку под курсором. PgUp и PgDn листают текст. Enter убирает отметку «новое» с выбранного квеста. Esc и правая кнопка закрывают окно.

Когда игра добавляет запись, тема поднимается вверх в своей вкладке. Точка рядом с названием и число на вкладке отмечают непросмотренное. Журнал открывает вкладку с последним непросмотренным квестом. Справа свежий текст идет первым. Порядок обновлений отслеживается с начала текущей игровой сессии. При загрузке журнала из сейва исходный порядок берется из сохранения.

## Установка и сборка

Скачай артефакт `G2NRquestbook` из успешного запуска [Actions](https://github.com/piratvasyamorexod-alt/G2NRquestbook/actions/workflows/build.yml). Разархивируй его и положи `G2NRquestbook.vdf` в `Gothic II\Data\Plugins`. Если предыдущая версия уже установлена, замени файл. Перезапусти игру.

Для сборки на Windows нужны Git, CMake и Visual Studio 2022 с инструментами C++ для Win32. Запусти `.\Build-Windows.ps1` из корня репозитория. Файл появится в `release\G2NRquestbook.vdf`.

## Проверка в игре

1. Добавь новую запись к старому квесту из середины списка. Убедись, что квест поднялся в своей категории и получил отметку. Повтори с двумя квестами, затем добавь еще одну запись к первому.
2. Открой длинный текст и пролистай его колесиком и PgUp/PgDn. Переключи все вкладки мышью и стрелками.
3. Закрой через Escape и правой кнопкой. Повтори после Alt+Tab и загрузки сохранения.
