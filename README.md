# G2NRquestbook

Родной журнал в Gothic II — кал. Листать квесты стрелочками в 2026 году? Да ну нахрен. Переделали окно, теперь им можно нормально пользоваться мышкой.

Игра пишет «Журнал обновлён» — открываешь дневник, а квест уже наверху своей вкладки. Рядом бронзовая точка, пока не ткнёшь в квест. В тексте старые записи сверху, свежие снизу. Окно в нашей оливке с бронзовой рамкой и нашим курсором.

## Управление

- **L** открывает журнал, если ты не менял клавишу.
- **ЛКМ** выбирает вкладку или квест. Колёсико листает список слева или текст справа, смотря где курсор.
- **ПКМ** и **Esc** закрывают окно.
- Стрелки и **Tab** тоже работают. **PgUp / PgDn** листают текст, **Enter** убирает точку у выбранного квеста.

После загрузки сейва журнал берёт порядок квестов из сохранения и отмечает только новые обновления.

## Установка

Нужны Gothic II «Ночь Ворона» 2.6 (fix) и Union. Мод показывает записи из игры или установленного мода. Инспектор «Одиссеи» ставится отдельно.

Скачай архив `G2NRquestbook` из успешной сборки в [Actions](https://github.com/piratvasyamorexod-alt/G2NRquestbook/actions/workflows/build.yml). Достань `G2NRquestbook.vdf`, кинь его в `Gothic II\Data\Plugins` и перезапусти игру. Если файл уже есть, замени его.

## Сборка

На Windows нужны Git, CMake и Visual Studio 2022 с C++ для Win32. Запусти `.\Build-Windows.ps1` из корня репозитория. Готовый файл будет в `release\G2NRquestbook.vdf`.
