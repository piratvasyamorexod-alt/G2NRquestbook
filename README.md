# G2NRquestbook

Мышь в штатном журнале заданий Gothic II «Ночь Ворона». Плагин рассчитан на Union и движок Gothic II Addon 2.6 (fix). Подходит для штатного журнала «Одиссеи» и работает отдельно от Odyssee Quest Inspector.

## Управление

Открой журнал обычной игровой клавишей. По умолчанию это **L**.

- Левая кнопка выбирает категорию, открывает запись и нажимает штатные стрелки списка.
- Колесико листает список заданий или открытый текст на три строки за шаг.
- Правая кнопка возвращает на один уровень назад, как Escape.
- Клавиатурное управление и оформление берутся из игры. Курсор использует бронзовую стрелку из «Журнала экспедиции» и восстанавливается после Alt+Tab.

## Установка и сборка

Скачай артефакт `G2NRquestbook` из успешного запуска [Actions](https://github.com/piratvasyamorexod-alt/G2NRquestbook/actions/workflows/build.yml). Разархивируй его и положи `G2NRquestbook.vdf` в `Gothic II\Data\Plugins`. Перезапусти игру.

Для сборки на Windows нужны Git, CMake и Visual Studio 2022 с инструментами C++ для Win32. Запусти `.\Build-Windows.ps1` из корня репозитория. Файл появится в `release\G2NRquestbook.vdf`.

## Проверка в игре

1. Открой штатный журнал, кликни по всем четырем категориям и пролистай длинный список колесиком и стрелками.
2. Кликни по строке после прокрутки и проверь заголовок открытого задания. Пролистай длинный текст до конца.
3. Выйди правой кнопкой. Отдельно войди в список через Enter и переключи категорию кликом. Повтори после Alt+Tab. При закрытии журнала управление возвращается игре.
